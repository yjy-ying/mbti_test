MBTI 互動式網站規格書


本專案旨在設計一個具備互動性的 MBTI 人格測驗網站，讓使用者能透過 12 道選擇題，初步了解自身在 MBTI 四個向度中的傾向，並在完成測驗後取得對應的人格結果。
本網站以娛樂與自我探索為主要目的，不作為正式心理測驗或臨床評估工具。

功能特色
- 12 題選擇題測驗
- 題目對應 MBTI 四個向度：E/I、S/N、T/F、J/P
- 完成後自動計算 MBTI 類型
- 顯示人格特色、盲點與分類結果
- 可重新測驗
- 單頁式操作，無需登入、無需資料庫、無需後端

技術方式
- HTML
- CSS
- JavaScript
- 全部整合於單一 index.html

說明
本網站主要用於娛樂與自我探索，不作為正式心理測驗。
